# Brain Tumor Detection & Classification System

An AI-powered, MLOps-enabled clinical diagnostic portal built with TensorFlow, Streamlit, OpenCV, and Plotly.

# Getting Started & Installation Instructions

1.Download the project as a ZIP archive.
2.Extract the ZIP folder to your preferred location on your computer.
3.Open VS Code or PyCharm, then click File > Open Folder and select the extracted project folder.
4.Open the built-in terminal in your editor and run the following commands:

# Step 1: Create a virtual environment
python -m venv venv

# Step 2: Activate the virtual environment On Windows (Command Prompt / VS Code Terminal):
venv\Scripts\activate

.\venv\Scripts\Activate.ps1

# Step 3: Upgrade pip and install all required packages (combining  libraries and requirements.txt dependencies)

python -m pip install --upgrade pip
pip install streamlit plotly matplotlib tensorflow opencv-python scikit-learn Pillow pydicom numpy pandas scipy reportlab fpdf2 google-genai

# Step 4: Run the Streamlit web application
streamlit run app/streamlit_app.py
